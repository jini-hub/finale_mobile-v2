# Finale 2.0 v1.0

대한민국 상속 절차를 PC/모바일에서 단계별로 정리하기 위한 반응형 웹앱 프로토타입입니다.

## 실행
별도 빌드가 필요 없습니다. `index.html`을 열거나 GitHub Pages에 그대로 배포하세요.

## 구현 기능
- PC / 모바일 반응형 UI
- Finale 전용 SVG 일러스트 4종
- 상속 절차 7단계 가이드
- 상속재산/채무 간단 계산기
- 상속방법(단순승인/한정승인/상속포기) 비교
- 필요서류 안내
- 진행 체크리스트 및 브라우저 localStorage 저장
- 정부24 안심상속 공식 페이지 연결
- 다크모드

## 중요
본 프로젝트는 법률자문 서비스가 아니라 절차 정리용 정보 도구입니다. 사건별 사실관계에 따라 필요한 서류와 법적 효과가 달라질 수 있으므로 실제 제출·처분 전에는 담당기관/전문가의 최신 안내를 확인하세요.

## 검증에 사용한 공식 공개자료 (2026-09-18 확인)
- 대한민국 법원 전자민원센터: 상속포기/한정승인 기간 및 관할 안내
- 정부24: 사망자 및 피후견인 등 재산조회 통합처리 신청(안심상속)
- 국세청: 상속세 신고·납부기한 및 제출서류 안내
