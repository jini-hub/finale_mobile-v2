# Finale 2.0 Design Integrated

## 포함
- PC/모바일 반응형 디자인
- 직접 제작한 SVG 일러스트 5종 (가족/문서/재산/사무실/빈 상태)
- 상속 절차, 재산조회, 필요서류, 신청, 진행상황 화면
- localStorage 기반 체크/진행상황 저장
- 정부24·대한민국 법원·국세청 공식 페이지 연결

## 배포
저장소 루트에 모든 파일을 업로드하고 GitHub Pages를 `main / root`로 설정하세요.
